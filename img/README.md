## Guidance
- **Authentic beats stock.** Real photos of the team, real companies, and the markets you work in build far more trust than generic stock on a finance site.
- **Licensing:** if you use stock, pull from Unsplash or Pexels (free, commercial use). Don't lift images from Google.
- **Format:** export JPG (or WebP) at ~70–80% quality; aim for under ~300 KB each so pages stay fast.
